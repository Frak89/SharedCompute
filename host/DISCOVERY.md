# SharedCompute 1.2
The active Android node replies to private-LAN UDP discovery on port 50553 with protocol, request nonce, reported device name, public certificate fingerprint and TLS port 50552. No pairing token is broadcast. Discovery metadata is unauthenticated and does not grant access. Clients must still explicitly obtain a pairing line from the device, verify the certificate pin and authenticate using the activation token. Stop the node to revoke it. Existing 1.1 clients can continue manual pairing. All supported ARM64 Android devices may advertise; no device model is assumed. Wi-Fi client isolation, firewall, platform local-network permissions or multiple networks can prevent discovery. Raw RPC remains loopback only. No ADB required for this path.
