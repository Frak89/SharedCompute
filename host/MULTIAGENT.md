# MultiAgent AI Teamwork
Run SharedCompute-MultiAgent.exe from the dedicated Actions workflow or python host/multiagent.py (Python 3 with Tk). Separate from the RPC worker. No browser.
- Start your local model servers first; Ollama, LM Studio or llama-server must expose a compatible /v1/models and /v1/chat/completions.
- Discover known PC endpoints; add trusted LAN endpoints explicitly, one per line as device | URL. Only private IPs or localhost are accepted. Give endpoints on the same physical device the same name to avoid concurrent loads. No automatic LAN-wide scan or filesystem GGUF detection.
- Optional: discover authorized Android ADB devices with model APIs already running on ports 11434, 1234 or 8080. The RPC worker alone is not an LLM server. The app does not install or start an Android model runtime. ADB forwarding is removed on normal app close. Do not expose unauthenticated APIs on untrusted networks.
- Select up to eight available models. Master Auto deterministically prefers CyberTiel, then coder models, then PC; it is not a benchmark. Manual selection must be included in team. Each device's models run sequentially; different named devices run in parallel.
- Drafts are independent, then agents receive each other's bounded proposals and the original prompt. The master generates 2–8 selectable alternatives if it follows the requested JSON format; malformed responses fall back to actual proposals. All requests use the server's model context limits. Streamed tokens are displayed with agent labels.
- Human checkpoint: choose an option and add feedback or request new options. No final synthesis until approval. A second checkpoint lets you accept the final answer, copy it, or ask for revision. The original prompt is retained.
- Stop requests cooperative cancellation; a pending network read can take until its timeout. Closing the app removes ADB forwards best effort. No cloud endpoints, no automatic file writes or command execution, no CyberTiel chat API integration yet. Python tests mock model calls; real network and device tests still needed.
